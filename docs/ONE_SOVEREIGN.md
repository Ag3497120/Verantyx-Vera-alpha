## ask() の一本道 (2026-08-19 現在)

```
問い
 ├ intent_frames (問いの型)
 ├ math_sim / mathlib_witness (数)
 ├ 文書空間 (store, 連合と並記・絶対に合流しない)
 ├ structural_diff (AとBの違い)
 ├ 推論核 ja_consensus_ask ── 断面収束+同点換え門(既定ON)
 │    └ ANSWER → Writer(形だけ) → written
 ├ (核が型付き沈黙) census = 階段の種 SEEDED / 盗まれた部品なら選挙を開かない
 ├ context (直近核で補完・可視)
 ├ meaning_descent / 単位分解 (降下)
 ├ arm_schema 注釈・gap台帳・typo再問い・remedy
 └ 型付き判定 + 経路 + 文 + 出典 (全て隣に添える、票は一つ)
```

## 一つに「束ねなかった」もの (測定が禁じた合流)

- 区切り違いソブリン→判定census (蔵書外誤答 0→8)
- 二言語の同居 / 引用の核ラダー混入 / 単位を核の語に足す (各実測で悪化)
- 写しマトリョーシカ (恒等写像)
- 会話調文型→法令調Writer (レジスタ混合は束ね)

線は一本: **票に入れるか、手渡すか**。ask() は手渡しの連鎖であり、
選挙は推論核の中に一つだけある。
