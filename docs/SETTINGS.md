## Modes

Six independent families. They are listed together because each one appears alone in the interface, which makes every switch look like *the* mode switch; knowing which family a setting belongs to tells you what it cannot affect.

### Operation mode / 動作モード

How much the agent asks before it acts.

Where: **Settings › Agent**  ·  Source: `Engine/ArtifactEngine.swift:11 (OperationMode)`

| Option | What it does | When to pick it |
|---|---|---|
| **Gatekeeper** / ゲートキーパー | Every change passes a review gate before it lands. | Shared or production code, where an unreviewed edit is expensive. |
| **Automatic** / 自動 | Runs to completion without stopping to ask. | A task you have already scoped and want finished unattended. |
| **Detailed** / 詳細 | Asks questions and gathers context as it goes. | An unclear task, where the first answer is likely to be the wrong one. |

### Inference route / 推論経路

Where your text goes: local machine, cloud, or masked before sending.

Where: **Settings › Privacy**  ·  Source: `Engine/HybridEngine.swift:20 (InferenceMode)`

| Option | What it does | When to pick it |
|---|---|---|
| **Local Only** / ローカルのみ | Nothing leaves the machine. | Anything you cannot send to a third party. |
| **Cloud Direct** / クラウド直送 | Text is sent to the cloud provider unmodified. | Public code, where capability matters more than exposure. |
| **Privacy Shield** / プライバシーシールド | Identifiers are masked before the request is sent. | Cloud capability on code with names you would rather not ship. |
| **Paranoia Mode** / パラノイアモード | AST-level surgical masking before sending. | The strictest option that still uses the cloud. |

### MCP execution mode / MCP 実行モード

Whether an MCP tool call has a deadline.

Where: **Settings › MCP**  ·  Source: `Engine/MCPEngine.swift:140 (MCPServerConfig.ExecutionMode)`

| Option | What it does | When to pick it |
|---|---|---|
| **AI Priority** / AI 優先 | No automatic timeout; runs until it finishes or you stop it. | Long tool calls you intend to wait for. |
| **Human Mode** / 人間モード | A 60-second outer deadline. | Interactive work, where a hung tool should give up rather than block you. |

### BitNet memory depth / BitNet 記憶の深さ

| Option | What it does | When to pick it |
|---|---|---|
| **L1 Only** / L1 のみ | Only the shallowest layer is read. | Faster, when deep context is not paying for itself. |
| **L1-L3 Full** / L1〜L3 全層 | All three layers are read. | The default; richer context per call. |

### Vera save approval / Vera 保存の承認

When you are asked to approve what Vera writes to memory.

Where: **Settings › Memory**  ·  Source: `Engine/VeraSaveApprovalRequest.swift:6 (VeraSaveApprovalMode)`
