# 事前登録 — 木への主経路移行と浅層棚建設の判定基準

登録時刻: 2026-08-14 16:10 JST。
浅層スライス測定(jawiki 10k冒頭・探針200)は背景で実行中であり、
**この基準はその結果を誰も見ていない時点で登録された。**
結果を見てから基準を動かすことは、内部オラクルの罠と同族の穴であり、
この文書の存在理由はそれの防止である。以後の変更はこのファイルへの
追記(取り消し線と理由つき)でのみ行い、書き換えない。

## 前提の固定(判断の土台)

- 危険度の序列は常に「静かな誤り > 見える混在」。平坦合併の語義汚染が
  今すぐの火事でないのは facet_origin が面単位で出所を言う=失敗が
  可視だから。したがって木への移行は「正しさの修理」ではなく
  **「可視化を分離に昇格させる工事」**として急ぎ度を見積もる。
- 木側の既知実測: 経路選択 52/52・誤0(表面伝導つき)、木複製の証人帯
  正解143・誤0・棄権260。つまり木は**「誤らないが黙る率が上がる」形**
  だと分かっており、賭けはそこにない。測るべきは答え数の代償と
  棄権の型内訳である。

## 判定1 — 木降下を答えの主経路にするか

測定プロトコル(固定): 同一ストア世代で、法令400バンク+200問バンク
+スライス探針200を、平坦合併(現行)と木降下(conduct_tree経由)の
両方に同時に流す。語義汚染型の誤りは「SHOWNの面の facet_origin が
主題と別記事に属する答え」と定義して数える。

- **移行する**: 木降下の答え数が平坦比 **80%以上** 保たれ、かつ
  語義汚染型の誤答が実測で減る(差が0より大きい)場合。
- **移行しない**: 答え数が平坦比 **60%未満** の場合。木は
  facet_origin 強化(可視化の深化)に留め、主経路は平坦のまま。
- **中間帯(60〜80%)**: 併置に留める — 木の判定を注釈として平坦の
  答えの隣に出し(帯は票にならない)、拒否型の内訳から需要を測って
  再判定する。
- **無条件の不合格**: 減った答えが型付き棄権に変換されていない場合
  (無言の消失があれば数字が良くても不合格)。棄権の型内訳の報告自体
  を合格条件とする。

## 判定2 — 浅層wiki棚(全量〜140万記事)を建設するか

測定プロトコル(固定): 実行中のスライス測定が返す
「探針200の穴率 before / after(+10k冒頭棚)」を使う。

- **全量建設に進む**: スライスの1記事あたり穴閉鎖効率を全量に線形
  外挿して、穴率が **現行の50%以下** に落ちる見込みの場合。
  (線形外挿は楽観であることを明記した上で、しきい値は外挿値に置く)
- **建設しない(需要駆動のみ継続)**: 外挿しても穴率半減に届かない
  場合。浅層の広さは growループ(穴台帳の需要駆動)でのみ広げる。
- **建設する場合の置き方(再確認・変更不可)**: 独立した棚。答えの
  censusに入れない。地図(closing_domains)と証人としてのみ働く。
  合併への追加は本文書の範囲外であり、別の事前登録を要する。

## 登録者注記

数字(80/60/50)は木の既知実測(誤0・黙る率上昇)と法令400/400の
維持要求から選んだ。答え数80%は「黙る代償は許すが、5問に1問を超えて
失うなら分離の利得が代償に負ける」という読み。60%は「3問に1問失う
なら主経路の資格がない」という読み。異論は結果到着前のみ受け付ける。

## 追記 2026-08-15 — 判定1の実行結果と、基準そのものの欠陥

測定: `tools/measure_tree_migration.py`(法令400+問200+探針200=800問、
同一ストア世代、平坦=公開連邦のask、木=同じ5分野ストアを葉にした
conduct_tree降下+葉のask)。

**登録基準の機械的適用結果は「移行する」**:

    答え数        平坦 715 → 木 618   (86.4%、80%の線を超える)
    汚染(登録定義) 713 → 616         (差>0、減った)
    無言の消失    0                   (166 UNKNOWN_NO_ROUTE ほか型付き)

**しかしこの合格は数字の欠陥による。実行しないことを推奨する。**

1. 汚染は率で見ると動いていない: 99.72% → 99.68%。絶対数が97減ったのは
   答えが97減ったからであり、1問あたりの汚染は**同一**。登録文が
   「差が0より大きい」と絶対数で書いたため、**答えを減らすだけで通る**
   条項になっていた。
2. 登録した汚染定義は「別**記事**」であり、木が分けるのは「別**分野**」。
   実例: 時効 の SHOWN面は 時効.txt / 消滅時効.txt / 公訴時効.txt の
   3記事だが**全て同一分野(指名)**。木は原理的にこの数を動かせない。
   つまりこの定義は、木の効果を測れない。
3. 集約が per-bank の差を隠した: 法令400は99.5%保持だが、探針200(百科・
   指名の広さ)は**56.8%**で、単独なら「移行しない」の線(60%)を下回る。

以上により、~~判定1の結論に従って主経路を移行する~~ ではなく:

- 判定1の結果は「基準は通ったが、基準が測れていなかった」として記録する。
- 移行の可否は、**分野レベルの汚染率**(率で、絶対数でなく)と
  **バンク別の保持率**を新たに事前登録した上で再測定して決める。
- それまで主経路は平坦のまま。木は併置(注釈)にも進めない — 併置は
  中間帯の処置であり、今回の帯域判定自体が信用できないため。

この追記は結果を見た後に書かれている。だから**基準は緩めていない**:
合格を不合格に読み替えたのではなく、合格が意味を持たないことを
記録し、次の登録に持ち越した。数字を動かしたのではなく、数字が
何も言っていないことを言っている。

### 追記の続き — 分野レベルで測ると、木は実際に効いている(判定には使わない)

`tools/measure_tree_migration_note.py`(同一800問):

    分野をまたぐ答え   平坦 51/715 = 7.13%
                      木   16/618 = 2.59%   (相対64%減)

登録定義(記事違い)が99.7%で動かない一方、木が分けるはずの軸で測ると
汚染率は7.13%→2.59%に落ちる。**木は設計どおり働いており、基準がそれを
見られなかっただけ**である。これは判定1を覆す材料ではない(この数字は
結果を見た後に定義したので、判定に使えば事後の基準作りになる)。次の
事前登録が立つべき土台として記録する。

残る代償も同時に記録する: 探針200の保持率56.8%は、分野の広さを問う
問いで木が3〜4割黙ることを意味する。次の登録は「分野汚染率の低下」と
「バンク別保持率の下限」を同時に置かねばならない — 片方だけなら、
今回と同じ「通るが意味がない」基準になる。
