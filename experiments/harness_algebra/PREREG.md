# 事前登録: ハーネス代数 v0 — 呼び出し言語を数学で組み、実行で馴染ませる

日付: 2026-08-20。**この文書を書き終えてから測定を走らせる。**

## 構想(操作者、同日)

「ハーネスを細分化してストアに保存し、独自の呼び出し言語を中間に置き、
言葉を理解していなくても**数学だけで組み合わせをシミュレーション**して
から実際に組み、使ううちに馴染む」。

## 思想からの導出(法則の二分 — これを混ぜたら全部が無意味になる)

- **構造則**: インタプリタの構成そのものが保証する等式(wire_add の
  「学習した数学ではなく構成上正確な計算」と同じ線)。書き換え核に
  渡して、**実行の前に**組合せ空間を畳む。
- **経験則**: モデル(この実験ではモック)ごとに実行が earn する事実。
  証人 `verified:run:<モデル>@<日付>` つき、モデルが替われば失効する。
- 未検証の組合せは UNTESTED。**仮定される法則は存在しない。**

## 言語(閉じた表 — 記号6・構造則5)

    型:  H(ハーネス) / N(自然数 = 予算、既存)
    構成子: hact(N)→H     原子行為(番号はモック行為表の添字)
    記号: hseq(H,H)→H     直列
          hretry(H,N)→H   再試行(予算 n 回まで)
          htrunc(H,N)→H   入力の切り詰め(長さ上限 n)
          hjudge(H)→H     検証段の装着(不合格出力を棄てる)

    構造則(インタプリタの構成で真にする):
      A1  hseq(hseq(f,g),h)      = hseq(f, hseq(g,h))
      A2  hretry(hretry(f,a),b)  = hretry(f, mul(a,b))
      A3  htrunc(htrunc(f,a),b)  = htrunc(f, min(a,b))     ← 今日のmin
      A4  hretry(f, s(0))        = f
      A5  hjudge(hjudge(f))      = hjudge(f)

    偽の法則(反例が出るべきもの):
      F1  hseq(f,g) = hseq(g,f)          (順序は可換でない)
      F2  hretry(f,a) = f  (a=2で)       (再試行は無意味でない)
      F3  htrunc(f,a) = f                (切り詰めは無意味でない)

## インタプリタ(審判)

決定論のモックモデル2種の上でハーネス項を実行する:
    mockA: 最初の1回は必ず失敗し、2回目から成功する(不安定型)
    mockB: 入力が長さ6を超えると必ず失敗する(長文弱者型)
観測 = (成功したか, 消費した試行数, 出力)。**等式の意味 = 全ての接地
入力・全ての原子行為割り当てで観測が一致すること**(接地検査の定義)。

## 測定(完了基準5点 + 圧縮の実利)

- ① 構造則 A1..A5: 接地検査(列挙した接地ハーネス項×入力で両辺の
  観測一致)全通 + 予算側の恒等式(min/mul)は既存の証明器で PROVED
- ② 偽の法則 F1..F3: 接地検査が**反例(具体的な項と入力と観測差)**を
  名指して REFUTED
- ③ 判定保留: 交換則 htrunc(hretry(f,a),b) =? hretry(htrunc(f,b),a) は
  **測ってから**どちらかに置く(構成で真にしていないので、接地で
  反例が出れば REFUTED、出なければ UNTESTED のまま — 昇格しない)
- ④ 順序: 規則列反転で正準形の集合が不変
- ⑤ 独立検証: 予算側恒等式は Lean(既存経路)。接地検査は別種で再走
- **圧縮**: 深さ≤4の全ハーネス項を列挙し、構造則の書き換えで正準形へ
  畳む。項数 → 正準形数を報告(シミュレーションの実利の数字)
- **経験則**: mockA/mockB 各々で「hretry(f,2) が素の f より成功を増やす
  か」「htrunc(f,6) が成功を増やすか」を実行で earn し、
  **証人つき・モデル縛りの事実**として台帳へ。転移の実測 =
  mockA の事実を mockB に適用したときの成否も記録(生き残らないことの
  実証が目的 — 構造則だけが転移する)

## 採択基準

- G1: A1..A5 接地検査全通(1本でも反例 → その法則は棄却し構成を疑う)
- G2: F1..F3 全て反例つき REFUTED
- G3: 圧縮 — 正準形数 < 項数(数字は報告、しきい値は課さない)
- G4: 経験則: mockA と mockB で**採否が分かれる**事実が ≥1
  (モデル別ハーネスの実在の最小実証)
- G5: 順序反転不変・黙った昇格0

## 停止条件

G1違反 → インタプリタの構成の誤り。修理してから再測(法則は動かさない)。
これはモックでの器の検証であり、実LLMでの earn は次の段(凍結指示の
解除が前提)— **この事前登録は実LLMについて何も主張しない**。
