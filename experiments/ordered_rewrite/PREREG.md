# 事前登録: 向き付けは完全性を回復するか(閉包を破らずに)

日付: 2026-08-19 / 実測前に登録 / branching_rewrite の続き

## 前提(実測済み)
可換律 `?a + ?b → ?b + ?a` を足すと、正規形到達が 60/60 → **22/60** に
崩れる(予算切れ38 = a+b→b+a の無限往復)。健全性は崩れない。

## 仮説
崩れる原因は「元に戻れること」なので、**適用に向きを付ければ止まる**。
項の全順序を定め、**結果が真に小さくなる時だけ**可換律を適用する
(ordered rewriting / 順序付き書き換えの古典的手法)。

これは**探索ではない**。後戻りも分岐の試行もせず、規則の適用可否を
項順序という決定論的な述語で決めるだけ。格納された規則を、格納された
順序で適用する — **閉包の内側**にとどまる。

## 順序
`(項のサイズ, 印字の辞書順)` の辞書式。可換律は有限個の置換しか
生まないので、この順序で真に減少する適用だけを許せば停止する。

## 方法
branching_rewrite と同じ60式(同じ seed)で3腕:
  A 縮む規則のみ(基準)
  B 可換律を無向きで追加(既測: 22/60)
  C 可換律を**向き付きで**追加
各腕で: 正規形到達数 / 予算切れ / Lean(omega)通過 / 不健全

## 判定(事前)
- **健全性**: C で不健全 0(1件でも出れば失格、機序を分解する)
- **完全性**: C の正規形到達が B(22)より増える。60 に戻れば仮説通り。
- 加えて記録: C は `b + a` と `a + b` を同じ正規形に落とすか
  (落とすなら、向き付けは完全性の回復だけでなく**正規化の強化**でもある)
