# 実測結果: 向き付けは完全性を回復し、正規化を強化する

事前登録: PREREG.md / 生データ: results.json / 60式・同一 seed

| 腕 | 正規形到達 | 予算切れ | Lean通過 | 不健全 |
|---|---|---|---|---|
| A 縮む規則のみ(基準) | 60/60 | 0 | 60 | **0** |
| B 可換律を無向きで追加 | **19/60** | 41 | 19 | **0** |
| C 可換律を**向き付き**で追加 | **60/60** | 0 | 60 | **0** |

(B は branching_rewrite の 22/60 と僅かに違う。あちらはカーネルの
`_step`(定数畳み込みを含む)、こちらは実験側の薄い層で、畳み込みの
有無だけ差が出る。結論は変わらない。)

## 判定
- **健全性**: C で不健全 **0** — 合格
- **完全性**: 19 → **60/60** — 仮説どおり完全回復
- **追加の所見**: C は `(b + a)` と `(a + b)` を**同じ正規形 `a + b` に
  落とす**。向き付けは完全性を取り戻すだけでなく、**無向きの可換律では
  区別されたままだった置換を同一視する** — 正規化の力そのものが増える。

## なぜ閉包の内側にとどまるか
向き付けは「結果が項順序で真に小さくなる時だけ適用する」という
**決定論的な述語**であり、後戻りも分岐の試行もしない。格納された規則を、
格納された順序で適用するだけ。**探索ではない。**

順序は `(項のサイズ, 印字の辞書順)` の辞書式。可換律は有限個の置換しか
生まないので、この順序で真に減少する適用だけを許せば停止する
(順序付き書き換えの古典的手法)。

## これが道筋に対して意味すること
branching_rewrite で「崩すのは大きくなることではなく元に戻れること」と
記録した。今回はその裏を取った形で、**元に戻れなくすれば崩れない**。

つまり `停止しない規則の扱い` は ⚠️ から ✅ へ動く。ただし
**帰納法の壁(目標の不在)は一歩も動いていない** — 向き付けは
等式理論の中での話で、新しい等式法則を立てる力は与えない。

## 追測: 一つの規則の偶然ではないか(run_symmetric.py)

対称規則を4本に増やした(加法可換・乗法可換・加法結合の並べ替え・
乗法結合の並べ替え):

| 腕 | 正規形到達 | 予算切れ | Lean通過 | 不健全 |
|---|---|---|---|---|
| 対称4規則・無向き | 19/60 | 41 | 19 | **0** |
| 対称4規則・**向き付き** | **60/60** | 0 | 60 | **0** |

規則を4本に増やしても、向き付けは**完全性を保つ**。可換律1本の偶然では
なかった。

## 正準形になっている
`a + b + c` の全順列 × 2通りの括弧付け = **12式が、すべて単一の正規形
`a + (b + c)` に落ちる**。

これは完全性より強い性質で、**同じものを同じ形に落とす**(正準化)。
無向きの可換律では、置換は区別されたまま残り、しかも止まらなかった。
向き付けは「止まる」だけでなく「同一視する」を同時に手に入れている。

実務的な含意: 等式の同値判定が**両辺を正規形にして比べるだけ**で済む。
`(b + a) - (a + b)` のような式が 0 に落ちる、という形で効く。
