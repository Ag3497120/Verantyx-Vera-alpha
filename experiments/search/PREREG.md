# 事前登録: 探索 — 人の指示を全部外したらどこまで行くか

日付: 2026-08-19 / 実測前に登録

## 前実験で人がやっていたこと
帰納法は動いたが、次の3つを**私が指定していた**:
1. どの変数に帰納するか
2. どの補題を先に証明するか(T3 は T1/T2 を規則として与えた)
3. 命題をどう並べるか

「選ぶこと=探索」と書いたが、**選べるかどうかは測っていない**。測る。

## 駆動層(閉じた手順・決定論・乱数なし)
    直接:   両辺を既知規則で正規形にし、一致すれば証明
    帰納:   **目標に現れる各変数について順に**試す
            基底 = 変数を 0 に置換
            段   = 変数を新しい定数 k に置換し、仮定を規則として加える
    不動点: 未証明の目標を全部試す → 1つでも証明できたら**規則として
            加え**、もう一巡する。増えなくなるまで繰り返す

3 が「どの補題を先に」を自動で解く: 依存の無いものが先に通り、
それが規則になって次を解錠する。**人は順序を与えない。**

## 探針(ヒントを一切与えない)
加法・乗法の定義だけを与え、目標は順不同でまとめて渡す:
    G1 add(0,x) = x            G5 mul(0,x) = 0
    G2 add(s(x),y) = s(add(x,y))  G6 mul(x,0) = 0
    G3 add(x,y) = add(y,x)     G7 mul(s(x),y) = add(mul(x,y), y)
    G4 add(add(x,y),z) = add(x,add(y,z))   G8 mul(x,y) = mul(y,x)

## 測るもの
1. **ヒント無しで何本証明できたか**(G1〜G8)
2. 不動点に何巡かかったか / 探索した枝の数
3. **証明したと主張した各命題を Lean が検査**(独立検査)
4. 詰まった目標について、**何が足りないか**を具体的に記録
   (「探索が足りない」で終わらせない — 汎化が要る等を名指しする)

## 判定(事前)
- **健全性**: 証明したと主張したものが Lean で偽なら**失格**
- 到達数は合否ではなく測定値。0本でも「駆動層はこう詰まる」を記録する
