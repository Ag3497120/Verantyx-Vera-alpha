# 追測: 非単調性の機序と、**自分の証明器に見つけた健全性の穴**

## 発端
第3段で「G3+G8 を同時に渡すと G8 が解けない」— G8 単独なら解けるのに、
**目標を増やしたら解けなくなった**。非単調で明らかにおかしい。

## 機序1: 自分で証明した定理が、自分の系を壊す
G3(可換律)を証明すると `add(?x,?y) → add(?y,?x)` として昇格される。
**これは無向きの対称規則**で、branching_rewrite で「a+b→b+a の往復で
停止しない」と測ったものそのもの。実測: G3 昇格後、`add(a, b)` が
**UNKNOWN_BUDGET** になる。

修理は既測の手法をそのまま使う — **対称な補題は向き付きで昇格する**。

## 機序2: **予算切れを「一致」と読んでいた**(重大)
向き付けを入れたら全8本が 8/8 → 6/8 に「退行」した。おかしいので
元の 8/8 を調べたところ、**8/8 の方が偽だった**:

```python
if nf(lhs_0) != nf(rhs_0): continue      # ← 予算切れは None
```
両側が予算切れだと `None != None` は False なので、**基底が閉じたことに
される**。G3 昇格で系が停止しなくなった後、G4/G7/G8 は
**空虚に「証明」されていた**。

実測: G3 昇格後の系で G4 の基底は x/y/z のどれでも `lhs=None rhs=None`。

**Lean はこれを捕まえられなかった** — 命題自体は真だからである。
独立検査は「主張が真か」を見るのであって「**導出が本物か**」は見ない。
真の命題を空虚に「証明」しても、検査は通ってしまう。

修理: `None` は一致に数えない(基底・段の両方)。

## 修理後の本当の数字
| 条件 | 証明 | 未証明 |
|---|---|---|
| 推測なし・向き付けなし(元の条件) | **5/8**(G1,G2,G3,G5,G6) | G4,G7,G8 |
| 推測+向き付け・G3単独 | **G3** | なし |
| 推測+向き付け・G8単独 | **G8** | なし |
| 推測+向き付け・**G3+G8** | **2/2** | なし ← **非単調性は解消** |
| 推測+向き付け・全8本 | **6/8**(G1〜G6) | G7,G8 |

Lean 検査 10/10 VERIFIED・不健全 0。

### 訂正
前節に書いた「**8/8**」は**予算切れの誤読による偽の数字**だった。
本当は 5/8 で、推測と向き付けを足して 6/8。G3+G8 の非単調性は解消した。
全8本での G7/G8 は、向き付けの下では届かない — これが現在の到達点。

## 教訓
- **独立検査(Lean)は導出の本物さを保証しない。** 真の命題を空虚に
  「証明」しても通る。導出側の健全性は導出側で守るしかない。
- **退行に見えた変更が、実は誤りを露出させた。** 6/8 は 8/8 より
  「悪い」のではなく、**正しい**。
- 今日3件目の「自分の断定・自分の数字の訂正」。

# 追測2: 残った非単調性の正体は **AC正規化の不在**だった

## 追い方
G8(全8本の中)が落ちる → 段の両辺を見ると **G7 を必要としている** →
G7 を直接追うと、段で:

    s(add(k, add(x, mul(x, k))))   vs   s(add(mul(x, k), add(k, x)))

**両辺は `k + x + x*k` の並べ替え**である。可換律(G3)も結合律(G4)も
規則として持っているのに、閉じない。

## 二段階で分かったこと
1. **G3 だけを向き付けると停止すらしない**(両辺とも UNKNOWN_BUDGET)。
   G4 が無向きのまま残るため、G3↔G4 で往復する。
2. **G3+G4 を向き付けると停止するが、正規形が一致しない**:
       A → s(add(add(mul(x,k), x), k))
       B → s(add(add(k, x), mul(x,k)))
   **停止するが合流しない。**

### 訂正: 「正準化」の主張は固定具に限った話だった
ordered_rewrite で「a+b+c の12通りが単一の正規形に落ちる=正準化」と
書いた。それは**その固定具については真**だが、**任意の AC 項には
一般化しない**。ここが反例である。項順序による向き付けは
**停止性**を与えるが、**合流性(AC正準性)は与えない**。

## 解: AC正規化(平坦化+整列)
比較の直前に、AC演算子(add/mul)の入れ子を平坦化し、整列して組み直す:

    A のAC正規形  s(add(k, add(mul(x, k), x)))
    B のAC正規形  s(add(k, add(mul(x, k), x)))   ← 一致

これは項順序の外側で行う**比較の正規化**であって、書き換え規則ではない。
探索でも推測でもなく、決定論的な整列。

## 結果(run_ac.py)
    AC正規化 + G3/G4/G8 向き付け

    証明   **8/8**(G1〜G8)
    Lean   **8/8 VERIFIED**、不健全 0
    巡 1 / ノード 14

**非単調性は完全に解消した。** 単独でも全8本でも同じだけ解ける。
