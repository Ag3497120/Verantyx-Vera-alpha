# 実測結果: 文型の旧仮名(2026-08-19)

## 発端
残タスクに「文型汚れ(つづつて)」があった。破損だと思っていたが、
原XML(322AC0000000224.xml 戸籍法)が literally 「戸籍は、これをつづつて
帳簿とする。」と書いている — **旧法の正字**(促音の大書き)であって
収穫の破損ではなかった。つまり分類が誤っていた。

## 実測(範囲)
speakable 597文型のうち **16本(2.7%)** が旧仮名を運ぶ:
  なつた6 / もつて3 / あつた3 / によつて3 / であつて1 / つづつて1
生成に出ていた例(実測済み): 「経費によつて精算する」「利用でなくなつた
移動」。読み手には誤字に見える。

## 触ってよい理由(provenance)
文型は**主張を運ばない** — compose_ja 冒頭「A form's source wrote that
shape, not the claim the shape ends up carrying」。引用(quote_in_words の
行、文書の text)はこの表を一度も通らない。**形の綴りだけ**を現代表記へ。

## 修理
Writer.load に閉じた9対の表(実測に現れたものだけ。「かつた/とつた」等の
類推追加はしない)。型の再導出の後に適用(綴り変更が型判定を動かさない
順序)。現代表記の双子と衝突したら回数を合算 — 綴りを直した結果として
頻度の実測を捨てない。
