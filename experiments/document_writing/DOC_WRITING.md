# 文書の言葉で紡ぐ — 8/18に却下した文生成の、門つき再挑戦

事前登録 2026-08-19。実行前に書き、実行後に数字だけを埋める。

## 8/18の失敗(記録済み)

一般知識のWriter(jawiki由来1,329文型)を文書語彙に当てたら:

    精算は、グリーンをグリーン車さない。   ← 切れ端+意味不明
    精算は、グリーン（がいしょくほう）である。 ← 除去済み汚染語の再出現

「文書に無いことは答えない」の大原則に反する危険な出力として却下し、
参考文は見出しのみの構成(「〜についてそれぞれ定めがあります」)に留めた。

## なぜ今は違うか — 却下理由が個別に潰れた

| 8/18の症状 | 原因(後日特定) | 今日の門 |
|---|---|---|
| グリーン車**さない** | 文型のスロット境界が語の途中(434/1329本) | slot_boundary_ok (4974f55) |
| **がいしょくほう** | 語彙外の断片が充填に素通り | 語彙の門 (4974f55) |
| 取り合わせの狂い | VERBAL_NOUNS空+選択無配線 | 0881ff2 |

## 設計 — 引用行そのものが辺ライセンス

- 内容は**引用された行1本の内容連だけ**。同じ行に書かれた語どうしは
  同一文共起そのもの — 連合の辺ライセンス(「コーパスが実際に書いた対
  だけが文になれる」)の最強形が、構成上ただで手に入る。
- 充填は writer.vocab を通った語のみ(切れ端は入らない)。語が2未満なら
  **黙る**(参考文と引用だけが立つ) — 断片より沈黙。
- 文型は今日の門を通った集合のみ(modality none・positive・境界OK)。
- 生成文は constructed と明記し、**引用の隣**に置く。引用・verdict は
  一切変えない。票にも入れない — 束ねず重ねる。

## 測定

hisho.txt(8/18と同じ文書)への同じ質問群+危険を出した「精算」系:
交通費の上限は / グリーン車は使えますか / 会議費は / 対象経費は /
申請期限は / 領収書は / 精算とは。

数える: (a) 生成文中の語彙外内容連(切れ端率) — 8/18は複数、目標0。
(b) 汚染語(がいしょくほう類)の出現 — 目標0。(c) 生成文の全内容語が
引用行∪主語に含まれる率 — 100%が要件(発明ゼロの検査)。(d) 文が出た
質問数(沈黙のコスト)。

## 停止条件

(c)が100%を割る=引用に無い主張が1文でも出るなら、文書側生成は再度
却下し、見出しのみの参考文に戻す。

## 判定と配線

8/18の却下理由(切れ端・汚染・取り合わせ)は3門で個別に塞がれ、同じ
文書・同じ質問群で全て0になった。文書側生成を **quote_in_words**
(stacked.py) として実装し、engine.ask の文書扉(早期/後退)と
vera_ask_documents 扉に配線 — 下書きは constructed・licence=quoted_line
と明記され、引用と verdict には一切触れない。fork
DOCUMENT_DRAFT_IS_LICENSED で契約(発明ゼロ・非語行では沈黙)を固定。
forks 154/154、P1 9問・P2 20問回帰なし。

## 残る限界(正直に)

文はまだ不器用(「新幹線と利用を移動する」)。語は全て行から来ているが、
行の**構文役割**(何が主語で何が目的語だったか)は運ばれていない — 次の
軸は行の係り受けを閉じた規則で読み、充填の役割を行に合わせること。
