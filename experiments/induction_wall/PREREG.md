# 事前登録: 道筋はどこで止まるか — 帰納法の壁

日付: 2026-08-19 / 実測前に登録

## 問い
「未解決問題への道筋」は、道の存在ではなく**どこで途切れるか**でしか
検証できない。前2実験で分かっていること:
- 演繹は閉包を破らない(構造→Lean 30/30)
- 書き換えは健全で、完全性は規則の向きで決まる(可換律で60→22)

次に確かめるべき境界は、**全称命題を立てられるか**である。

## 実は既に一部答えが出ている(再確認する)
前実験の検査式は `theorem t (a b c : Int) : 原式 = 簡約 := by omega` で、
これは**全ての整数について**の主張である。つまりカーネルは変数を含む項を
書き換えて、Lean がそれを全称命題として通した。**等式理論の範囲では
全称命題を証明できている。** まずこれを明示的に数え直す。

## 本題: 帰納法を要する命題
`∀ n m : Nat, n + m = m + n` のような命題は、等式の書き換えだけでは
到達できない。**帰納法は別の推論規則**であり、規則集合を増やしても
出てこない。

## 方法
A群 20本: 等式恒等式(変数つき、帰納法不要)
  → ①simplify で両辺を正規形にし、一致すれば導出とみなす
  → ②Lean が `by omega` / `by rfl` で検査
B群 10本: 帰納法を要する自然数の命題
  → ①同じ手順を通す
  → ②Lean が `by omega` で通るか / `induction` を要するか

## 判定(事前)
これは合否ではなく**境界の特定**である。記録するもの:
1. A群で ①が導出し②が通った数(等式理論での全称証明の実力)
2. B群で ①が導出できた数(0 を予測する — 予測が外れたらそれ自体が発見)
3. B群を Lean が omega で通せた数(命題の難易度の目安)
4. **①が誤った導出を出した数**(健全性 — ここが0でなければ重大)

そして「帰納法を足すには何が要るか」を、コードの形で名指しする。
