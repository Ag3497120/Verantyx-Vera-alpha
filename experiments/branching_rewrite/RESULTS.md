# 実測結果: 分岐のある書き換え — 健全だが、完全性は規則の形で決まる

事前登録: PREREG.md / 生データ: results.json

## 本測定(200式、30.8秒)
    正規形到達(ANSWER)   200/200  (100.0%)
    Lean が独立に検査     200/200  VERIFIED  (不健全 0)
    予算切れ               0
    平均の縮み            2.9倍

## ただし、この結果は規則集合の性質で説明が付く
既定の8規則(add_zero/mul_one/mul_zero/sub_zero/sub_self)は**全て項を
縮める**。だから停止性が構造的に保証されており、**そもそも詰まりようが
無い**。事前登録で「分岐があるので正規形に至れない可能性がある」と
書いたが、その分岐は**この規則集合では噛まなかった**。

## 追測: 縮まない規則を入れると、どこで崩れるか(60式)
| 規則集合 | 正規形到達 | 予算切れ | Lean通過 | 不健全 |
|---|---|---|---|---|
| 縮む規則のみ(基準) | 60/60 | 0 | 60 | **0** |
| **+ 可換律** `?a+?b → ?b+?a` | **22/60** | **38** | 22 | **0** |
| + 分配律 `?a*(?b+?c) → ?a*?b+?a*?c` | 60/60 | 0 | 60 | **0** |

**可換律で完全性が崩壊する**(60→22)。理由は明白で、a+b → b+a → a+b の
無限往復を、leftmost-innermost・最初に発火・**後戻り無し**のカーネルは
止められない。予算切れ38件はすべてこれ。

分配律は項を大きくするが**向きが一方向**なので停止する。
つまり崩すのは「大きくなること」ではなく「**元に戻れること**」。

## この実験の中核
**健全性は全条件で 0/0 のまま崩れなかった。** 詰まった38件は
`UNKNOWN_BUDGET` を返し、**間違った正規形を出していない**。
これはこの構造の一貫した性質 —「分からない時は黙る」が、推論層でも
そのまま成立している。

崩れるのは完全性だけで、しかも**規則の形(向きを持つか)で決まる**。
これは規則集合の設計問題であって、カーネルの欠陥ではない。実用の
書き換え系(Lean の `simp`)が「単純化補題は向きを持つ」ことを要求するのと
同じ結論に、独立に到達している。

## 次に必要なもの(正直に)
可換律のような対称規則を扱うには、後戻り(探索)か順序付け(項順序に
よる向き付け)が要る。前者は探索で、この構造が持っていないもの。
後者は Knuth-Bendix 完備化が扱う古典的問題で、**規則側の前処理**として
なら閉包を破らずに足せる。どちらを取るかは、まだ測っていない。
