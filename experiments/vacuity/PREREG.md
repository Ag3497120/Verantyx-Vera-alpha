# 事前登録: 空虚な証明を、構造的に作れなくする

日付: 2026-08-19 / 実測前に登録

## 今日見つけた穴(再掲)
駆動層が **予算切れ同士を「一致」と読み**、真の命題を空虚に「証明」した。
Lean は捕まえられなかった — **独立検査は主張の真偽を見るのであって、
導出の本物さは見ない**。報告した 8/8 は偽で、本当は 5/8 だった。

単発の修理(None を一致に数えない)は済んでいる。だが同じ**形**の穴は
他にもあり得る: 規則集合が壊れて**何でも等しくなる**場合である。
例えば `?x → 0` のような規則が1本混じれば、全ての等式が「証明」できる。
このとき各証明は個別には整合しており、内部からは気づけない。

## 番犬(canary): 偽の等式が証明できないこと
規則を増やすたびに、**偽であることが分かっている等式**が依然として
証明**できない**ことを確かめる:
    0 = s(0)
    s(0) = s(s(0))
    0 = s(s(0))
これらが証明できるようになったら、規則集合は壊れており、
**その時点以降の全ての「証明」は無価値**である。

## 測るもの
1. 今日の探索(全8本・AC正規化つき)の全行程で、番犬は**一度も鳴かない**か
2. **番犬が本当に働くか** — 故意に壊れた規則(`add(?x, ?y) → 0`)を混ぜたら
   鳴るか。鳴かなければ番犬自体が無意味
3. 番犬が鳴いた時点で、その規則集合で何本の偽が「証明」できるか

## 判定(事前)
- 正常系で番犬が鳴いたら、**現在の探索は既に壊れている**ことになる。
  その場合は探索の結果を全て取り下げて機序を分解する。
- 故意に壊した系で番犬が鳴かなければ、番犬の設計が失敗。作り直す。
