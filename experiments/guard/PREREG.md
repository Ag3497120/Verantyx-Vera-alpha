# 事前登録: 番人 — 10時間の実地試験が名指した限界を、エンジン側で塞ぐ

日付: 2026-08-21。**この文書を書き終えてから測定を走らせる。**

## 経緯(二つの別セッションの実測)

10時間のゲーム実験の結論: Vera が LLM に対して構造的に勝る場所は
**約束の台帳**(set_covenant / check_reply / fading_covenants)であり、
最良の用途は Claude Code のフックに挟む番人。別マシンでの実装が
5経路を通し、同時に限界を名指した:

    1. 約束に破棄の経路が無い(「もう使っていいよ」を取り下げられない)
    2. 字面照合 — 🎉 そのものは捕れず、語「絵文字」しか捕れない
    3. 英語の指示から約束が立たない
    4. PostToolUse 欠落 — ファイルに禁止語を書いても素通し
    5. 起動の穴 — 橋(常駐)が寝ていれば 15〜45秒 fail-open

## エンジン側の変更(4点)

1. **retire_covenant** — 削除ではなく退役。retired の印・退役の引用・
   ターンを持ち、check/fading から外れるが**履歴は残る**(台帳の精神)。
2. **文字クラスの照合(閉じた表・1クラスのみ)** — 禁止語が「絵文字」
   または "emoji" のとき、返答内の絵文字コードポイントそのものを検査し、
   見つけた文字を名指す。クラス表はこの1項のみ(「日本語」クラスは
   識別子の構文解析が要り、開いた賢さになるので入れない — 正直な限界)。
3. **extract_covenants** — 指示文→約束の抽出を器官に(フック側の字面
   規則を一元化)。閉じた規則: 日本語(〜を使わないで/〜しないで/
   必ず〜して)+ **英語**(never use X / don't use X / do not use X /
   always run X)。読めない文からは立てない(推測しない)。
4. **guard サブコマンド(高速経路)** — 連邦を読まず covenants.json
   だけを読む CLI。橋が不要になり、fail-open の窓が消える。
   目標: 1呼び出し 2秒以内(凍結バイナリの展開込み)。

## 同梱フック(tools/guard/)

hook_prompt.py(抽出+薄れ再注入)/ hook_stop.py(返答の照合)/
**hook_posttool.py(Write|Edit の内容を同じ照合に通す — 欠落していた覆い)**
+ settings 断片。全て guard サブコマンド直呼び(橋なし・fail-open なし。
CLI が落ちたら素通し = Vera の都合で作業は止めない、は維持)。

## 測定(完了基準5点)

- V1 正: 日本語+英語の指示から約束が立つ(en: "Never use emojis" が
  forbids=[emojis] になる)。retire 後は check が発火しない
- V2 反証: 🎉 を含む返答が、語「絵文字」なしで **BROKEN**(見つけた
  文字を名指す)。ファイルに禁止語を書く → hook_posttool が検出
- V3 拒否: 読めない指示(婉曲)からは約束が立たない(推測しない)。
  retire 済みの約束は fading にも出ない。ただし履歴は list で見える
- V4 順序: 約束の登録順を変えても check の判定集合が不変
- V5 速さ: guard サブコマンド1呼び出しの実測時間(凍結バイナリ)を報告。
  2秒超なら「橋は依然必要」と正直に記録

## 停止条件

V2違反(クラス照合が誤検出 — 絵文字の無い返答を BROKEN にする)→
クラス表ごと棄却(過検出の番人は切られる、が実地試験の教訓)。
