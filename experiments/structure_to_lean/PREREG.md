# 事前登録: 構造→Lean の閉ループ(既知の結果を再導出できるか)

日付: 2026-08-19 / 実測前に登録 / 操作者の判断「未解決問題は構造的に不可能、
構造的帰結の方が早い」を受けて、**帰結の側**だけを測る。

## 問い
`rewrite_kernel`(規則を格納し、許可された規則だけを適用する項書き換え)が
出した結論を、**Lean が独立に検査して通るか**。

これは「未解決問題を解けるか」ではない。**既に解けている結果を、構造だけで
再導出し、機械の審判に通せるか**という、その手前の測定である。
既知を再導出できないものが未知を導出できることはない。

## 体制(束ねず重ねる)
    ① 演繹層  rewrite_kernel + allowed(格納規則のみ適用)
    ② 判定層  lean_witness.verify(Lean 4.34.0-rc1、ローカルに実在を確認)
    ③ 昇格    ②が VERIFIED を返したものだけを結果として数える

②は①の出力を一切信用しない。①が嘘をついても Lean が落とす。

## 方法
`rewrite_math.rewrite_add` の 202規則(桁上がり加算を規則データとして表現、
解釈器は「桁」が何かを知らない)で a+b を導出し、その結論を Lean の
`theorem : a + b = c := by decide` として書き出して検査する。
探針: 決定論的に選んだ 30 組(seed 固定)。

## 判定(事前)
- ①が ANSWER を出した組について、②が **VERIFIED 30/30**
- ①が誤った値を出した場合、②が **UNPROVEN で落とす**(嘘が通らないこと)
  — これを確かめるため、故意に1件改竄した項も通す
- forks は全数緑のまま

満たせば「構造→機械審判の閉ループが成立する」と記録し、満たさなければ
どの段で落ちたかを記録する。
