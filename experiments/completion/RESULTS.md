# 実測結果: 完備化は新しい等式法則を導く(12本、Lean 12/12)

事前登録: PREREG.md / 生データ: results.json / 1.8秒

## 入力(群の公理3本)
    assoc  (x * y) * z → x * (y * z)
    unit   e * x       → x
    inv    i(x) * x    → e

## 出力: 12本の新しい規則、すべて Lean が VERIFIED

| 規則 | 導かれた等式 | 由来 |
|---|---|---|
| kb1 | `i(x) * (x * z) → z` | assoc × inv |
| kb3 | `i(e) * x → x` | kb1 × unit |
| kb4 | `i(i(x)) * e → x` | kb1 × inv |
| kb5 | **`i(i(x)) * z → x * z`**(対合) | assoc × kb4 |
| kb6 | **`x * i(x) → e`**(右逆元) | inv × kb5 |
| kb8 | `x * (i(x) * z) → z` | assoc × kb6 |

**kb6 は教科書どおりの帰結**である。公理は**左**逆元 `i(x) * x = e` しか
与えていないのに、完備化が**右**逆元 `x * i(x) = e` を導いた。
kb5 の対合も同様に公理に無い。

## 判定
1. **導出量**: 3 → 15(12本増、1.8秒)
2. **健全性**: **12/12 VERIFIED**(群を整数の加法として解釈し
   `* → +, e → 0, i(x) → -x` で Lean の omega に出した)。**偽は0本**。
3. **有名な帰結**: 右逆元・対合ともに出た。**公理に無い等式を立てた**。
4. **完備には到達しなかった**(打ち切り: 12本/12巡)。kb9〜kb12 は
   `x*(y*(y'*i(...)))` の形で項が伸びており、この順序
   (サイズ, 印字)では発散している。**正しい簡約順序(LPO/KBO)が要る** —
   古典的に知られた要件で、実装の不足であって原理の壁ではない。

## 道筋への意味
これまで「新しい等式法則の確立」を ❌(帰納法=目標が無いため)としていた。
**完備化はその一部を、帰納法を使わずに埋める。**

ただし埋まる範囲は明確に限られる:
- 完備化が導けるのは **与えた公理の帰結**だけ。
  `x * i(x) = e` は群の公理から従うから出た。
  `n + m = m + n`(自然数の可換律)は **加法の再帰的定義からは
  帰納法でしか出ない** ので、完備化では出ない。
- つまり **「公理の帰結を明示化する」力**であって、
  **「新しい公理系の真理を発見する」力ではない**。

## 未達(正直に)
- 簡約順序が素朴(サイズ+印字)。LPO/KBO を入れないと発散する対が残る。
- 完備化そのものは停止性が保証されない(古典的に半決定)。
- 帰納法の壁は**一歩も動いていない**。目標の概念は依然として無い。
