# 事前登録: 完備化は新しい等式法則を導けるか

日付: 2026-08-19 / 実測前に登録 / ordered_rewrite の続き

## 位置づけ
前回まで「新しい等式法則の確立」は ❌ だった。理由は帰納法(目標)の不在。
だが等式法則を得る道はもう一つある — **完備化(Knuth-Bendix)**。

格納された規則どうしの**重なり**から臨界対を計算し、両側を正規形に
落として一致しなければ、その等式を**新しい規則として加える**。
これは帰納法ではない。**格納された規則の帰結を明示化する**操作で、
根拠は全て格納済み — 閉包の内側にとどまる。

## 方法
群の公理3本を規則として与える(古典的な例):
    assoc   (x * y) * z  → x * (y * z)
    unit    e * x        → x
    inv     i(x) * x     → e
完備化を回し、導かれた規則を数える。

**検査**: 導かれた各規則を、群を整数の加法として解釈して Lean に出す
    * → +,  e → 0,  i(x) → -x
    例: `i(i(x)) → x` は `theorem (x : Int) : -(-x) = x := by omega`
これで「導かれた等式が本当に真か」を独立に確かめる。

## 判定(事前)
1. **導出量**: 元の3規則より増えるか(増えなければ完備化は何も生まない)
2. **健全性**: 導かれた規則を Lean が**全て VERIFIED** にする。
   1本でも偽が出れば失格 — 完備化の実装が壊れている。
3. **有名な帰結**: `x * e → x`(右単位元)や `i(i(x)) → x`(対合)のような、
   公理に無い等式が出るか。出れば「新しい等式法則を立てた」と言える。
4. 停止しない場合は、その事実と打ち切り時点の規則数を記録する。

これは合否ではなく**到達点の測定**である。ただし2(健全性)だけは合否。
