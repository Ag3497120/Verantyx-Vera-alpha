# 事前登録: 帯割れの特定性裁定 (REVERSE_SPECIFIC)

日付: 2026-08-19。**この文書を書き終えてから確認測定を走らせる。**
探索(seed 42、results_diagnose*.json)で仮説を作った。確認は**別の核集合**で行う。

## 背景(探索で分かったこと — 確認前の暫定)

300探針(seed 42)で:
- 順方向合意の敗因は証拠の不到達ではない(正解は候補に92%居る、
  殻上重なりも部分的に届く)。**axis_energy の 質量×名前一致 が
  被覆信号(正解3/3 vs 勝者1/3)を溺れさせている。** 全facetで重なりを
  数え直す反実仮想でも 236敗中8勝のみ — 式の形が壁。
- 逆方向の帯が唯一 → 182/182 正解。帯が割れても正解は帯から脱落しない
  (116/116)。
- 割れた帯では 特定性 = 被覆語数 / 面数 の一意最大が 66/116 で正解。
  誤答18の全てはマージン(一位/二位の特定性比) ≤ 2.17、正解66の
  中央値は 21.3。

## 規則(固定 — 確認測定で変更しない)

順方向が非ANSWERで、逆方向の被覆最大帯が割れている(≥2)とき:

1. 帯の各核の特定性 = |被覆語(facet∪名前語)| / max(1, 面数)
2. 一位が一意 かつ (一位の特定性 / 二位の特定性) ≥ **3.0** のとき、
   その核を verdict=REVERSE_SPECIFIC として返す。次点の核とマージンを
   回答に併記する(読者が裁定根拠を検査できる)。
3. それ以外(同点一位・マージン<3.0)は現状どおり棄権。

しきい値 3.0 は探索データで誤答0だった最小の切りの良い値。
**確認測定の結果を見てから動かさない。** 1.5 / 2.0 / 5.0 の成績も
記録するが、参考値であり採否には使わない。

## 確認測定

- 核集合: `random.Random(4242).sample(rich, 600)` から **seed 42 の
  300核を除外**して先頭300核。探針は同じ生成規則(mid_facets, seed=999)。
- 3族:
  (a) 裸3語
  (b) 自然文包装「{t1}と{t2}と{t3}に関係するのは何ですか」
      (frame_stripped 適用、PREREG_PROMOTION2 と同一)
  (c) 名前形100本(「{核名}とは」)の順方向 ANSWER 不変検査

## 採択基準(全て満たすこと)

- P1: (a) で REVERSE_SPECIFIC の誤答 **0**(正解数は問わない — 増分が
  1でも、誤答0で増えるなら門は無傷)
- P2: (a) で REVERSE_SPECIFIC の正解 ≥ **20**(それ未満なら効果が
  細すぎ、配線の複雑さに見合わない — 不採択)
- P3: (b) が (a) と一致(正解数の差 ≤ 2、誤答は 0 のまま)
- P4: (c) 100/100 不変
- P5: 既存 REVERSE_UNIQUE の成績(帯唯一の正解)が悪化しない

## 停止条件

P1 違反(誤答 ≥1)→ 規則は不採択。しきい値を上げての再測は
**新しい事前登録**を書いてから。
