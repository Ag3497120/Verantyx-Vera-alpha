# 事前登録: E1 の効果測定 — 環状視界 vs 幾何学的視界を、既存ハーネスで

日付: 2026-09-01。**この文書を書き終えてから測定を走らせる。**

## 発端

E1(幾何学的視界: 実立体では対極が見えず、回転か退避だけが対極を
向く動き)は、fork が**構造の差**だけを固定して勝敗を宣言していない
(cross_geometry_forks の冒頭に明記: 「どちらが良く推論するかは
設計者の問いで、実クエリが要る」)。ハーネス
`verantyx/consensus_ab_eval.py` は在るのに、実行結果が experiments/ の
どこにも記録されていない — 測る道具だけあって測定が無い状態。

## 方法

ハーネスを**一切改変せず**そのまま走らせ、標準出力を全文記録する。
比較軸はハーネスが定義済みのもの:

1. 視界 topology(ring / geometric)— E1
2. マトリョーシカ carry A/B/C vs 平坦
3. 配置粒度(fine / coarse)

正解はハーネスの自己導出(店が持つ核を問う・見たことのない語を問う)。
合成コーパスなので、**この測定で既定値を切り替えることはしない** —
実ストアの数字ではないため。決めるのは「合成でも差が出るか、出ないか」
と、その向きだけ。

## 記録するもの

- accuracy / honesty / invented(名指し問い)
- exact / defensible / answer_rate(facet のみの問い)
- ハーネス自身の妥当性検査(INVALID / 飽和 NOTE)の出力

## 採択基準

- J1: ハーネスの妥当性検査を通る(INVALID が出たらこの測定は無効で、
  その旨だけを記録する)
- J2: 数字がどうであれ全文を RESULTS.md に写す。差が 0 なら 0 と書く
  (飽和 NOTE が出たら「この コーパスでは順位付け不能」が結論)

## 既定値の扱い

geometric_visibility の既定(False)は**この測定では変えない**。
実ストア(89k核、リポジトリ外)での再測が切り替えの条件で、それは
設計者の判断。ここでは判断材料を作るだけ。
