# 事前登録3: 候補追記を質量順から特定性順へ

日付: 2026-08-19 / 実測前に登録

## 不合格の実測(PREREG2 のゲート3)
jawiki 本文投入で ja 核 740k→1,188k。**同一の問い文字列**(投入前の店から
生成した300問)で両店を測ると:
    reachable 171 → 15 / wrong 206 → 223 / correct 1 → 2 / refusal 91 → 74
事前判定「wrong 非増加」に反する。**採用しない**のが既定の行動。

## 原因(機序)
候補追記は残枠を `-(overlap*1000 + mass)` で埋める。核が1.19Mになると
overlap=3 の核が数千あり、その中を質量が決める — jawiki のリードは汎用核
に巨大な質量を与えるので、正解の中頻度核が6枠から押し出される。
docstring が既に警告していた "tokyo vs film"(質量が本命を押し出す)が、
89k/740k では起きず 1.19M で起きた。

## 変分(1つだけ)
同点(overlap 同数)の中の順位を、質量降順から**特定性降順**へ:
    specificity = overlap / len(cross)
「自分の面のうち何割がこの問いに当たるか」。直接ヒット(名前一致)の順位は
一切触らない — 変えるのは追記ブロックの中だけ。

## 判定(事前)
採用条件: 同一300問で reachable が投入前(171)以上、かつ wrong が
投入前(206)以下。満たさなければ jawiki 本文の葉を退避(before_jawiki)へ
戻し、不合格として記録する。
