## 抽出器の修理4件(全て実測が導いた・基準は動かしていない)

1. **束縛は宣言行に居ない** — mathlib は section の `variable` 行に置く
   (`variable [CommMagma G]` → `theorem mul_comm : ∀ a b : G, …`)。
   スコープ追跡(namespace/section/variable)と ∀ 剥がしを実装。
2. **「Nat明示の等式」は実在しない** — 初回18本の正体はテスト治具
   (.lake/packages・MathlibTest)。治具ディレクトリを断片から除外し、
   ファイル走査を Mathlib/ 優先に(外部パッケージの同名が dedup で
   本物を食っていた)。
3. **型クラス許可表 → 決定手続きに格上げ**(事前登録からの逸脱、強い側へ)。
   この断片(変数・数字・+・*)では両辺が ℕ⊂ℤ 上の多項式なので、
   次数+2点の格子一致 ⇔ 恒等式。仮説束縛(h : a = 0 等)を無視して
   無条件輸入しても、門が偽を必ず落とす — 実測で**仮説つき定理273本を
   反駁**(left_inv_eq_right_inv、charp.eq 等、全て正しい棄却)。
   判定不能(規模超過)は輸入しない。
4. **加法版はテキストに存在しない** — `@[to_additive]` が生成する。
   属性を検出し *→+ / 1→0 の閉写像で双子を導出、**双子も同じ決定門を
   通す**(two_mul の双子 2+n=n+n は門が反駁 — 写像の雑さは門が受ける)。
   双子18本が加法側を埋めた。

## 意味

- 「この定理は証明済みか」(名前照会)しかできなかった mathlib 資産が、
  **179,641文の検索可能な文在庫 + 50本の即使用可能な等式規則**になった。
  証明器が発明した補題は、以後 mathlib の名前で**引用**できる —
  再証明でなく参照(W4)。
- 決定門は fork にすべき不変条件: 「断片の輸入は決定手続きを通ったもの
  だけ。判定できないものは輸入しない」。
- 50本という数字が正直な現在地でもある: mathlib の等式知識の大半は
  +・*の外(∘・∪・↑・abs・min…)にあり、署名を広げるたびに決定門の
  設計(その署名で同一性が決定可能か)が要る。次の拡張は署名ごとに
  事前登録で。
