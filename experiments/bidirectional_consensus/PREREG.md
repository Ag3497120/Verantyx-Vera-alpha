# 事前登録: 双方向の重ね(順方向×逆方向の相殺)

日付: 2026-08-19 / 実測前に登録 / 発案は操作者
「構造を一方からしか見ていない。逆からやったものを重ねて、まとめて
投入することで相殺する」

## 向きの定義
- 順方向(現行): 問いの語 → 名前が一致する core を引き、殻で合意 → 勝者W。
  実測済みの欠陥: 候補に正解が居なくても相対選挙が当選者を出す
  (誤答278/300)。絶対門は「1語重なれば合格」しかない。
- 逆方向(新): core → 問い。各 core の facet 集合が問いの内容語を
  どれだけ覆うか(被覆数、同点は質量の小さい方=特定的な方)。
  問いを見ずに core の側から読む — 順方向とは誤りの出方が別種。

## 重ね(束ねない)
票は混ぜない。3腕を別々に測る:
  a) forward: 現行そのまま(基準)
  b) reverse: 逆方向の1位をそのまま答えとする(参考測定)
  c) layered: 順方向の勝者Wが、逆方向の上位(全語被覆、無ければ最大被覆
     の同点帯)に**入っている時だけ** ANSWER。入らなければ
     UNKNOWN_DIRECTION_DISAGREEMENT(両方向の言い分を名乗る型付き拒否)。
     どちらの向きの点も相手に加算しない — 門であって加点ではない。

## 方法
retrieval_reach と同一ハーネス(vera.db ja、300探針、seed同一、読み取り専用)。

## 判定(事前)
layered の採用条件: 誤答が forward より減り、正答が減らない。
reverse 単独は参考(採用対象ではない — 単独の向きは単独の誤りを持つ)。
