# The Cross — a tap-through 3D research special (English)

Single-file three.js piece (three.js 0.160 from cdnjs) that walks through the
cross structure in 13 scenes: concept → facets → placement → query energy →
six sections → search (lexicographic moves, one escape) → convergence and the
centre seat → generation by reading order → typed refusal → tie abstention →
circulation → closing.

- `trace_en.py` — records the real engine step by step on a 6-concept English
  store (same functions `run_consensus` uses; asserts the final verdict matches).
- `traces_en.json` — the recorded log embedded into the page.
- `template3d.html` — the page with `__TRACES__` placeholder.
- `the_cross.html` — the finished page (open in a browser; tap / → / space to
  advance, drag to orbit, wheel to zoom).

The store is a synthetic model (legal-flavoured, not real statutes). The motion
is the engine's; the scale is a model.
